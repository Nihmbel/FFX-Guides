Übersicht: So spielst du Krieger beim Leveln

5 Regeln, die alles vereinfachen Gameplay
  1. Verteidiger (Tankhaltung) im PvE praktisch immer an.
  2. 3+ Gegner = AoE, 1–2 Gegner = Single Target.
  3. Cooldowns benutzen, nicht aufsparen (besonders in Dungeons).
  4. Später: Blutaura zuerst drücken, dann weitere Defensives.
  5. Waffe (Axt) ist Slot #1. Wenn nur 1 Upgrade: die Axt.
Tipp: Skills in Rotation immer mit translate="no" markieren, falls du Browser-Übersetzung nutzt.
Rotation-Merksätze Schnellcheck
  • Single: Combo sauber und später Burst-Knopf auf Cooldown.
  • AoE: AoE-Combo → später Burst → AoE-Spender.
  • Wenn HP fällt: Sturmkeil (früh) / später Blutaura.
Wenn du in einem Abschnitt einen Skill-Namen anders siehst: schick mir den exakten Tooltip-Namen aus deinem Client, dann passe ich’s 1:1 an.

Gear-Meilensteine: Wann lohnt sich Ausrüstung wirklich?

Poetik-Meilensteine (Kauf: Set + Waffe) Empfehlung Slot #1: Axt
  • Level 50: Poetik-Set + Axt (Mor Dhona)
  • Level 60: Poetik-Set + Axt (Idyllshire)
  • Level 70: Poetik-Set + Axt (Rhalgrs Wacht)
  • Level 80: Poetik-Set + Axt (Eulmore)
  • Level 90: Poetik-Set + Axt (Radz-at-Han)
  • 90→95: Poetik 90 trägt meist problemlos bis ~95
Waffenregel: Wenn deine Axt 10+ Level hinterher ist → 1× aktueller Dungeon oder eine günstige Axt (Händler/Marktbrett). Sonst: MSQ reicht.

Level 10–30 (Marodeur → Krieger freischalten)

Fokus: Basis-Combo + erster Dungeon Gear: MSQ reicht • Axt im Blick Wechsel: Jobstein auf 30
Single (1–2 Ziele): Gewaltiger Hieb → Verstümmelung AoE (3+ Ziele): Tollwut (spammen) (optional: Tollwut → Kahlrodung) Defensiv: Schutzwall wenn HP schnell fällt Verteidiger im PvE anlassen
Gear-Hinweis (10–30) Minimal
  • Dungeon-Farmen ist nicht nötig. 1× Story-Dungeon reicht.
  • Axt nur ersetzen, wenn sie 10+ Level hinterher ist.
  • Ziel Level 30: Klassenquests machen → Jobquest → Jobstein anlegen.

Level 30–50 (Krieger-Kern: 3er-Combo + AoE-Combo)

Fokus: Sturmbrecher vs. Sturmkeil AoE: volle AoE-Combo Gear: Poetik auf 50
Single (Default – Schaden/Buff): Gewaltiger Hieb → Verstümmelung → Sturmbrecher Single (wenn du mehr Heilung brauchst): … → Sturmkeil AoE (3+): Tollwut → Kahlrodung → Mithril-Gewitter Defensiv: Schutzwall / Rachsucht rotieren (nicht sparen)
Gear-Hinweis (30–50) Axt-Check
  • MSQ + Dungeon-Drops reichen fast immer.
  • Nur wenn deine Axt 10+ Level hinterher ist: 1× aktueller Dungeon oder günstige Axt.
  • Level 50: Poetik-Set + Axt holen (großer Sprung).

Level 50–60 (Urkraft + Spender)

Fokus: Urkraft ausgeben Spender: Himmelszorn / Dezimieren Gear: Poetik 50 → Poetik 60
Single (Boss): Gewaltiger Hieb → Verstümmelung → Sturmbrecher → (Urkraft da?) Himmelszorn AoE (3+): AoE-Combo → (Urkraft da?) Dezimieren Sustain/Defensiv: Urinstinkt (später Upgrade) aktiv nutzen Gleichgewicht als Notfall-Heilung
Gear-Hinweis (50–60) Poetik
  • Level 50: Poetik-Set + Axt holen → trägt stark.
  • Level 60: Poetik-Set + Axt in Idyllshire holen.
  • Dazwischen kein Farmen nötig, solange die Axt nicht massiv hinterher ist.
Hotbar (50–60) – Platzhalter: assets/img/warrior/hotbar-de-50-60.png

Level 60–70 (Burst-Fenster)

Fokus: Burst-Knopf auf Cooldown Burst: Innerer Impuls Gear: Poetik 70
Boss / Single: 1–2–3 (mit Sturmbrecher) → Innerer Impuls → Himmelszorn spammen (+ Aufruhr / Ansturm zwischen GCDs) Trash / AoE: AoE-Combo → Innerer Impuls → Dezimieren (später: AoE-Upgrade im Burst)
Gear-Hinweis (60–70) Einfach
  • Mit Poetik 60 bist du in diesem Abschnitt sehr stabil.
  • Level 70: Poetik-Set + Axt holen (Rhalgrs Wacht).
Hotbar (60–70) – Platzhalter: assets/img/warrior/hotbar-de-60-70.png

Level 70–80 (Unkaputtbar-Phase)

Fokus: Sustain in großen Pulls Kern: Blutaura (Upgrade von Urinstinkt) Gear: Poetik 80
Dungeon-Pulls (2–3 Gruppen, wenn möglich): Pull groß → Blutaura → AoE-Combo → Innerer Impuls → AoE-Spender/Burst → bei Bedarf Gleichgewicht Merksatz: Je mehr Gegner, desto stärker heilt dein Sustain (weil mehr Treffer).
Gear-Hinweis (70–80) Poetik 80
  • Poetik 70 trägt dich zuverlässig bis 80.
  • Level 80: Poetik-Set + Axt holen (Eulmore).
Hotbar (70–80) – Platzhalter: assets/img/warrior/hotbar-de-70-80.png

Level 80–90 (Stabil & fertig – Endwalker-Flow)

Fokus: Routine Rotation: „Final light“ Gear: Poetik 90
Single: 1–2–3 (mit Sturmbrecher) → Innerer Impuls → Himmelszorn (+ Aufruhr / Ansturm) AoE: AoE-Combo → Innerer Impuls → AoE-Burst/Spender Defensiv: In Dungeons: Blutaura zuerst, dann Schutzwall/Rachsucht.
Gear-Hinweis (80–90) Poetik
  • Poetik 80 trägt bis 90 sehr entspannt.
  • Level 90: Poetik-Set + Axt holen (Radz-at-Han) – ideal für Dawntrail Start.
Hotbar (80–90) – Platzhalter: assets/img/warrior/hotbar-de-80-90.png

Level 90–100 (Dawntrail bis Max-Level)

Fokus: MSQ + Dungeons Gear: Poetik 90 bis ~95 Max: Level 100 Endgame optional
90–95: Poetik 90 ist meist ausreichend. MSQ-Upgrades mitnehmen, wenn sie passen. 96–99: Rotation bleibt gleich (meist Upgrades/Feinschliff). Waffe ist weiterhin Slot #1. 100: MSQ-Endgear + Dungeons/Steine/Raids nach Lust. Für normalen PvE-Alltag reicht MSQ/Dungeon locker.
Gear-Hinweis (90–100) Axt bleibt #1
  • Wenn Kämpfe spürbar länger werden: prüfe zuerst die Axt.
  • MSQ-Gear ersetzt nach und nach Slots – nicht grinden, einfach mitnehmen.
  • Endgame-Farming ist optional und hängt davon ab, wie „hoch“ du gehen willst.
